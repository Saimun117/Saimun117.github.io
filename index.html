About

Before that I competed in programming contests, up to the ICPC Asia West Continent Final in 2022. I still like problems that have a right answer and a time limit.

I take on freelance iOS projects and I'm open to full-time roles, remote or in Dhaka.

In development

  • Auto body reshape for Beauty Editor (in development): Apple Vision and MediaPipe pose fused per person to drive nine region sliders through a single-pass Metal warp, built with Claude Code as a pair programmer.

Freelance

I take on a few freelance projects at a time. The kinds of work I do best:

A new app, from empty project to the App Store

SwiftUI first, UIKit where it is the better tool. I set up App Store Connect, TestFlight and the review submission, so you end up with a shipped app, not a repository.

Subscriptions and paywalls

StoreKit 2, RevenueCat or Qonversion. Server-side verification with App Store Server Notifications, trial flows, and paywall and onboarding A/B tests wired to analytics.

Photo, video and drawing features

Metal, Core Image, Core Graphics, AVFoundation and Accelerate: brushes, masks, filters and exports that keep up with the frame rate.

On-device machine learning

Core ML and Vision. Converting and quantizing models, then measuring that accuracy survives the conversion before anything ships.
